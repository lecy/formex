# Apply a transform plan to values (v7, experimental)

Apply a transform plan to values (v7, experimental)

## Usage

``` r
fx_apply_plan(x, plan)
```

## Arguments

- x:

  A vector of values in the plan's `from` format.

- plan:

  An `fx_plan` from
  [`fx_plan_transform()`](https://lecy.github.io/formex/reference/fx_plan_transform.md).

## Value

The values in the plan's `to` format.
