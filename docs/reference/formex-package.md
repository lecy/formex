# formex: Format Expressions and Data-Type Detection for Research Data

A vocabulary and detection engine for the data types found in research
datasets. Provides a library of column detectors (identifiers,
geographies, temporal formats, currencies, codes, hashes, and more), a
dispatchable data-type registry, the formex format-expression syntax,
and the type/class/subclass ontology that names them.
'guess_data_type()' is the single entry point that other packages build
on.
