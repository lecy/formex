# Is it an ISO 8601 datetime?

Is it an ISO 8601 datetime?

## Usage

``` r
is_iso_datetime(x)
```

## Arguments

- x:

  A character vector.

## Value

Logical vector; `TRUE` for `YYYY-MM-DDThh:mm:ss` with optional
fractional seconds and `Z`/offset zone.
