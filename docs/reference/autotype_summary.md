# Summarize an autotype results table by mutation tier

Summarize an autotype results table by mutation tier

## Usage

``` r
autotype_summary(results)
```

## Arguments

- results:

  Output of
  [`build_autotype_results()`](https://lecy.github.io/formex/reference/build_autotype_results.md).

## Value

A data frame with columns `type`, `n`, and `pass_rate`.
